# 向野日光地图

`xiangye-daylight.json` 基于 [OpenFreeMap Bright](https://github.com/hyperknot/openfreemap-styles) 调整：优先显示中文地名，改用更轻的公园、水域、道路和建筑配色。矢量地图数据、字体和图标继续从 OpenFreeMap 加载；路线和地点标记由向野另行绘制。
