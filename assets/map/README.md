# 向野标准街道地图

`xiangye-street.json` 基于 [OpenFreeMap Bright](https://github.com/hyperknot/openfreemap-styles) 调整：优先显示中文地名，使用常见的浅色街道图配色，突出主干道、水域与公园。矢量地图数据、字体和图标继续从 OpenFreeMap 加载；路线和地点标记由向野另行绘制。
